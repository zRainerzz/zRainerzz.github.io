# ghaithkhedhri.me

Source for my personal site — built with plain HTML, CSS, and JavaScript, no framework, deployed on GitHub Pages with a custom domain.

## Stack
- HTML / CSS / vanilla JS
- [Three.js](https://threejs.org/) for the particle background
- [Web3Forms](https://web3forms.com/) for the contact form
- Hosted on GitHub Pages, custom domain via `CNAME`

## Structure
- `index.html` — the site
- `styles.css` — all styling
- `script.js` — nav, animations, 3D background, portfolio filters, modals
- `thankyou.html` — contact form success page
- `favicon.svg`, `ghaith.jpg` — assets

Live at [rainyz-world.me](https://rainyz-world.me).
